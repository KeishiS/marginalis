# 042: v0.3.0のリリース受入

## 状態

受入中。2026-07-25 に設計監査とセキュリティ再監査後の `cargo make release-gate` が成功し、
Rust、OpenAPI、RustSec依存監査、release package、強化したNixOS service sandbox、
実バイナリによるbackup・30日purge、Kanidm 1.10.4 TLS Discovery E2E を確認した。
OIDC ID tokenはKanidm 1.10の`ES256`を受理し、RSA署名方式を拒否する。
残作業は実配備した環境での
OIDC browser login と ChatGPT、Claude Code、Codex CLI の手動 MCP 受入である。

2026-07-25の最終候補再配備後、`GET /api/v2/health`、ルートbase URL用のauthorization server
metadataとprotected resource metadataは`200`になった。未認証MCP requestはmetadata URLを示す
Bearer challenge付き`401`、OIDC loginはPKCE S256と`groups_name` scopeを伴ってKanidmへ`307`を返した。
当初の事前確認で使った`.../marginalis`付きmetadata URLは、サブパスbase URL用であり本環境の
ルートbase URLには該当しない。残るbrowser loginと外部MCP clientの手動受入を開始できる状態である。
実Kanidm discoveryもissuer
`https://id.sandi05.com/oauth2/openid/marginalis`に対して`ES256`だけを広告し、
`groups_name`をsupported scopeに含めている。

ChatGPT Web UIの認可開始はclient originからform POSTされるため、Marginalisの承認form POSTと同じ
same-origin検査へ入って`same_origin_required`になっていた。認可開始のGET/POSTを状態変更のない共通処理へ
分離し、未ログイン時はPOSTを維持しない`303`でOIDC loginへ移動するよう修正した。認可を確定する承認form
POSTは引き続きsame-origin、session、CSRF tokenを必須とする。Claude.ai custom connectorのcloud接続と、
Claude Code CLIの明示port付きloopback callbackも受入対象として区別した。

再配備後の実clientでは、ChatGPTの認可開始POSTがOAuth parameterをURL queryに置くことを確認し、Claudeでも
同種の失敗が再現した。client自身のCSRF field名とMarginalisの承認field名が衝突しても誤分類しないよう、
field名による判別を廃止した。`/oauth/authorize`を状態変更のない開始専用、
`/oauth/authorize/consent`をMarginalisの承認確定専用endpointとし、開始POSTはqueryとform bodyを統合して
重複parameterが不一致なら拒否する。

## 目的

SQLite 正本、Kanidm group 認可、新 API、MCP OAuth、閲覧用 Web UI、ソフトデリートを含む
`v0.3.0` を、空の新環境で公開可能と判断する。

## 受入範囲

1. 空の SQLite を初期化し、`server-users` と `server-admins` による OIDC login と認可を確認する。
2. REST `/api/v2`、閲覧用 Web UI、MCP が同じ ACL と管理者可視性を適用することを確認する。
3. ChatGPT、Claude Code、Codex CLI の MCP OAuth login、read/write、認可取消を確認する。
4. ソフトデリート、復元、30 日経過後の自動 purge を確認する。
5. NixOS module、Kanidm 1.10 E2E、TLS、subpath、release gate を確認する。

## 公開時の方針

- `v0.2.x` の database、`dataDir`、API、MCP token は利用しない。運用者は新しい空環境として
  初期化する。
- `v0.2.x` の保存データを必要とする運用者は、旧環境を読み取り専用の退避物として保管する。
- archive 復元の自動受入は本リリースの必須条件に含めない。
