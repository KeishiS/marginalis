== 移行後の管理方針

* 今後の作業項目はGitHub Issuesだけで管理します。
* 完了済み記録は現行仕様へ書き換えず、タグ上の原文と公開履歴を保持します。
* 旧リンクを見つけた場合は、この表または表に記載した移行先へ置き換えます。
* 新しい上流提案は対象リポジトリのIssueとして作成し、Marginalis側のIssueから関連付けます。
