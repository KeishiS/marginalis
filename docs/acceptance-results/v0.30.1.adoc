== 今回の確認で重点を置く点

過去に``notes:read``だけへ同意したクライアントについて、設定画面のクライアント別上限が「未設定」と
表示され、実効上限がサーバー対応scope全体であることを確認します。画面を開いただけでは上限を保存せず、
利用者が「上限を設定」を実行した後だけ明示的な設定へ変わることも確認します。

未設定は追加scopeを自動付与する意味ではありません。同じクライアントから``notes:write``などを新しく
要求し、OAuth同意画面で許可するまでは、既存tokenのscopeが広がらないことを確認します。

SQLite schemaとarchive形式はv0.30.0から変わりません。更新前の通常の退避を行ったうえで既存の
schema 18へ配備し、databaseの作り直し、archive変換、MCPクライアントの再接続が不要であることを
確認します。

利用者、Cookie、token、認可code、PKCE verifier、実際のノート本文や書誌情報は記録しません。
