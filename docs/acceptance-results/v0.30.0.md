## 今回の確認で重点を置く点

OAuth同意画面では、完全な`client_id`を先に読み、クライアントが提供した表示名とredirect先を照合します。
長いCIMD URLも途中で省略されず、画面幅の中で折り返されることを確認します。

数式では、所有者マクロとして登録した`argmax`と`bm`、`mathtools`の`\coloneqq`が、閲覧画面と
編集プレビューで従来どおり組版されることを確認します。同時に、`\require{html}`やautoload対象の
入力が追加JavaScriptを要求せず、安全な失敗表示になることを確認します。

SQLite schemaとarchive形式はv0.29.0から変わりません。更新前の通常の退避を行ったうえで既存の
schema 18へ配備し、databaseの作り直し、archive変換、MCPクライアントの再接続が不要であることを
確認します。

利用者、Cookie、token、認可code、PKCE verifier、実際のノート本文や書誌情報は記録しません。
