## 今回の確認で重点を置く点

タグを並べる文書属性の名前が`:tags:`から`:marginalis-tags:`へ変わりました。既存のノート本文が
そのままでは受理されなくなるため、`migrate-archive`が文書headerの属性名を書き換えます。実データ
での移行を独立した区分として確認します。

SQLite schemaは13のままで、`dataDir`の作り直しは不要です。archiveへ記録する
`adocweave_package_version`と`note_profile_version`が変わるため、`0.23.0`と版`5`を記録した
archiveを`migrate-archive`で変換してから取り込みます。

引用スタイルの選択を追加したため、`:marginalis-citation-style: numeric`を書いたノートで、本文の
`[1]`と参考文献一覧の`[1]`が相互に移動できることをWeb UIで確認します。

利用者、Cookie、token、認可code、client secret、実際のノート本文や書誌情報は記録しません。
