== 今回の確認で重点を置いた点

関係の図では、文献の題名を点のそばへ常時表示せず、マウスのホバーとキーボードのフォーカスで
全文を確認できることを確認します。ノートの題名、支援技術向けの名前、図と同じ内容を示す一覧が
従来どおり使えることも確認します。

v0.25.1が書き出すarchive 13を``migrate-archive``でarchive 14へ変換し、ノート、所有者、ACL、
書誌情報、削除状態、revisionを保ったまま、空のschema 16へ復元できることを確認します。旧archiveに
存在しない数式マクロ設定は空の状態で追加します。

REST API、MCP、SQLite schema、現行archive形式、NixOSモジュールには変更がありません。これらの
経路は自動検証で回帰がないことを確認し、v0.26.0の同日受入結果と併せて公開可否を判断します。

利用者、Cookie、token、認可code、client secret、実際のノート本文や書誌情報は記録しません。
