## 今回の確認で重点を置いた点

OAuth同意画面が通常のWeb UIと同じ枠、文字、ボタンを使い、クライアント名、識別子、移動先のホスト、
要求されたscopeを確認できることを確認します。HTTPとHTTPSのどちらでも、`localhost`、IPv4、IPv6の
loopback redirect URIに、この端末上のアプリへ戻るという注意が表示されることも確認します。

所有者が閲覧画面からノートを削除し、削除済みノートの画面で題名、削除日時、完全削除予定、revisionを
確認して復元できることを確認します。共有先には削除操作と削除済みノートの情報が表示されず、復元後も
本文、タグ、ACL、参照、引用索引、数式マクロの適用が保たれることを確認します。削除・復元の送信中は
確認画面内にフォーカスが保たれ、失敗後に再操作できることも確認します。

関係の図では、点の吹き出しが図の枠からはみ出さず、マウスのホバーが終わった後にキーボードで
フォーカスしていた点の吹き出しへ戻ることを確認します。書誌の点は題名を常時表示せず、ホバーまたは
フォーカスした場合と、図と同じ内容を示す一覧で確認できることを維持します。

SQLite schema 16、archive `marginalis-archive-14`、AdocWeave package版0.27.0、note profile版5は
変更しません。v0.27.0のデータベースをそのまま起動でき、最新archiveを隔離した空のデータベースへ
復元できることを確認します。

利用者、Cookie、token、認可code、PKCE verifier、実際のノート本文や書誌情報は記録しません。
