== 今回の確認で重点を置く点

書誌情報は利用者が書いたAsciiDoc本文ではなく、外部ファイルや書誌ライブラリーから得たデータです。
表示時にAsciiDocへ組み立て直さず、構造化した値のままAdocWeaveへ渡します。これにより、書誌情報中の
文字を記法の開始条件に照らして個別にescapeする規則をMarginalis側に持ちません。

SQLite schemaは20から変わりません。v0.32.0のdatabaseを直接引き継げます。一方、archiveは解析に使う
AdocWeave package版を記録するため、archive 16をarchive 17へ明示的に変換します。変換前のarchiveを
残し、``validate-archive``と``verify-restore``に成功した出力だけを空のdatabaseへ取り込みます。

利用者、Cookie、token、認可code、PKCE verifier、実際のノート本文や書誌情報は記録しません。
