== 今回の確認で重点を置く点

この版は、v0.35.0で加えた本文の行の長さ制限を取り下げます。表示だけが変わり、ノートの本文、保存形式、
公開契約は変えません。

*段落の折り返し*: 幅の広い画面で、段落が本文領域の幅を使い、途中で折り返されないことを確認します。
報告のあった次の本文で確かめます。

....
生物学に不慣れな人向けに、DNA、遺伝子、RNAの関係を、
物質としての粒度と情報の流れの両方から整理します。
....

閲覧画面と編集画面のプレビューの両方で確認します。

*v0.35.0で加えた表示の維持*: 見出しが題名から本文まで段階的に小さくなること、定義リストで用語と説明を
見分けられること、表が要素の内側で横スクロールすることを確認します。取り下げたのは行の長さの制限だけで、
これらは維持します。

*狭い画面の表示*: 360px相当の幅で、メニューから各画面へ移動でき、画面全体が横へはみ出さないことを
確認します。

*既存databaseからの更新*: v0.35.0のschema 20を残したままv0.35.1を配備し、起動、OIDCログイン、
Web UI、既存のノートの表示を確認します。

*公開契約の差分*: OpenAPI、MCP tool schema、NixOS moduleのoption、SQLite schema、archive形式、
OAuth metadataとscopeについて、v0.35.0タグと比べた差分がないことを機械的に確認します。

利用者、Cookie、token、認可code、PKCE verifier、実際のノート本文や書誌情報は記録しません。
