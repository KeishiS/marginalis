== 今回の確認で重点を置く点

CSL-JSONの取り込みは外部文献管理ツールからMarginalisへの一方向操作です。外部サービスの認証情報や
元ファイルは保存せず、取込元の表示名、外部項目との対応、前回取込時の内容digestとrevisionだけを
保存します。DOIなどの一致は重複候補を示す根拠であり、自動統合の根拠にはしません。

事前確認はdatabaseを変更しません。適用時には、事前確認が基準にした書誌ライブラリーと取込元の状態を
同じtransaction内で再確認し、一つでも変わっていれば全体を保存しません。入力に含まれない書誌情報は
削除せず、既存項目へ外部側の内容を反映する場合もcitation keyを維持します。

v0.31.0のschema 19は直接使用せず、archive 15を書き出してarchive 16へ変換し、空のschema 20へ
取り込みます。v0.31.0には取込元と対応情報がないため、移行後に最初にCSL-JSONを取り込んだ時点から
記録します。MCPのclient登録とtokenは移行されないため、復元後に接続し直します。

利用者、Cookie、token、認可code、PKCE verifier、実際のノート本文や書誌情報は記録しません。
