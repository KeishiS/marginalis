== 今回の確認で重点を置いた点

``mathtools``拡張と、その依存先である``boldsymbol``をMarginalisのWeb UI配布物へ含めます。
Content Security Policyを維持した状態で両方の拡張ファイルを同一オリジンから読み込み、
``\coloneqq``を含むインライン数式とブロック数式を組版できることを確認します。

数式を含む表示を切り替えた場合も、組版済みの内容を維持し、以前の組版結果を現在の内容へ
混ぜないことを確認します。MathJaxの字体を含め、外部CDNへ接続しないことも確認します。

REST API、MCP、データベース、archive、NixOSモジュールには変更がありません。これらの経路は
自動検証で回帰がないことを確認し、v0.25.0の同日受入結果と併せて公開可否を判断します。
