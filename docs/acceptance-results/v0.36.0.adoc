== 今回の確認で重点を置く点

この版は、番号で示す引用スタイルの参考文献一覧を番号付きで表示します。あわせてAdocWeaveを0.36.0へ
更新するため、日本語の本文の表示と、archiveの取り込み手順が変わります。ノートの本文、SQLite schema、
REST APIの要求と応答、MCP tool schemaは変えません。

*番号付きの参考文献一覧*: ``:marginalis-citation-style: numeric``を指定したノートで、参考文献一覧が
番号付きで表示され、本文の``[1]``と一覧の1番目が対応することを確認します。同じ文献を複数回引用しても
項目と番号が1つだけであること、項目から本文の各引用位置へ戻れること、``author-year``のノートでは
従来どおり番号のない箇条書きになることも確かめます。

*本文が定義した参考文献との併用*: ``[bibliography]``ブロックで自分で定義した項目と``cite:``を同じ
ノートで使い、著者が書いた記述が優先されること、その除外によって番号が飛ぶ場合でも描画に失敗せず、
番号のない箇条書きとして残りの項目が表示されることを確認します。

*日本語の本文の空白*: 原文を途中で折り返した段落と、``結果は cite:[smith2024] です。``のように
macroの直前へ空白を置いた本文で、表示に余分な空きが残らないことを確認します。閲覧画面と編集画面の
プレビューの両方で確かめます。

*既存databaseからの更新*: v0.35.1のschema 20を残したままv0.36.0を配備し、起動、OIDCログイン、
Web UI、既存のノートの表示を確認します。

*archive移行・復元*: v0.35.1が書き出したarchive 17を``import-archive``が拒否すること、
``migrate-archive``で変換した後に、本番から隔離した空のschema 20へ復元できることを確認します。
復元後にノート、ACL、参照、削除状態、revision、作成経路、人手確認記録、書誌ライブラリー、取込元と
対応情報、数式マクロ設定が一致することを確かめます。

*公開契約の差分*: OpenAPI、MCP tool schema、NixOS moduleのoption、SQLite schema、archive形式、
OAuth metadataとscopeについて、v0.35.1タグと比べた差分が、広告するAdocWeave package版だけで
あることを機械的に確認します。

利用者、Cookie、token、認可code、PKCE verifier、実際のノート本文や書誌情報は記録しません。
