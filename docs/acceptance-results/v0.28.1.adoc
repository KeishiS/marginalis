== 今回の確認で重点を置いた点

ログイン後の戻り先は、文字列の前方一致だけでなく、固定した基準URLへ解決した結果のoriginとpathを
検査します。通常のノートURLとqueryは引き続き使用でき、URLの正規化後も``cookie_path``そのもの、または
その配下にあるpathだけを受理することを確認します。

OIDC login attemptは、発行時刻以前に期限が切れた行を、件数の確認と挿入と同じtransaction内で削除
します。日次の``purge-expired``は長期的な整理として維持し、有効なattemptの保存上限1,024件も変更
しません。

SQLite schema 16、archive ``marginalis-archive-14``、AdocWeave package版0.27.0、note profile版5を
維持します。v0.28.0の受入で確認したWeb UI、ノートの削除・復元、関係の図、MCPクライアント接続、
archive復元の結果を引き継ぎます。

利用者、Cookie、token、認可code、PKCE verifier、実際のノート本文や書誌情報は記録しません。
