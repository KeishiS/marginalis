== 今回の確認で重点を置いた点

既存ノートの更新プレビューは、編集権限を確認したうえで、保存後の表示と同じくノート所有者の
書誌ライブラリーを使って引用を解決します。閲覧権限だけを持つ利用者と対象外利用者には、ノートの
存在を開示しない応答を返すことを確認します。

archiveと文書の書き出しでは、途中まで書いたファイルが最終パスへ現れず、完了した内容だけを
確定します。既存ファイルを上書きしないこと、失敗後も再実行できること、隔離したデータベースへ
復元した論理内容が一致することを確認します。

書誌検索、共有設定、数式組版では、要求の完了順が入れ替わっても古い結果が新しい状態を上書き
しないことを確認します。MathJaxが生成した表示はContent Security Policyに違反せず、更新後に
不要な組版情報を保持しないことも確認します。

利用者、Cookie、token、認可code、client secret、実際のノート本文や書誌情報は記録しません。
