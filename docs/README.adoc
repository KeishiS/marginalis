== 文書の読み分け

現行の動作について資料間に差がある場合は、REST APIには``openapi.json``、システム要件には
``requirements.adoc``、設計には``architecture.adoc``、NixOSでの運用には``nixos.adoc``を優先します。

バージョン番号が付いた資料と完了済みIssueは、作成時点の記録です。現在の仕様を確認する目的では
使用しません。版ごとの変更内容と移行手順はGitHub Releasesを参照してください。過去の版に固有の
記録（v0.3.0再設計判断、変更履歴、版別受入結果、AdocWeave移行判断など）は、削除前の最終版で
ある``v0.36.0``タグ上の``CHANGELOG.adoc``と``docs/``から参照できます。探索サービスの連環（Renkan）は
https://github.com/KeishiS/renkan で開発しています。
