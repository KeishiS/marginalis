= 編集画面の装飾はAdocWeaveのspan注釈から導く

[#top]
* 状態: 採用
* 日付: 2026-08-20
* 関連Issue: \#516、\#517、\#518、\#519、\#520
* 関連ADR: xref:0003-codemirrorをasciidoc編集基盤に採用.adoc#top[ADR 0003]

== 背景

編集画面はAsciiDoc原文を素のテキストとして表示し、描画結果はプレビューへの明示的な
切り替えでのみ確認できます。強調や見出しの見た目を確かめるたびに執筆とプレビューを往復する
手間があり、編集欄で執筆中の原文をその場で装飾表示したいという要望があります。経緯と段階は
Issue \#516に記録しています。

目指す編集体験は、原文の文字列を正本のまま保ちながら、``**太字**``は太字で、見出しは大きな
文字で表示し、カーソル(選択範囲)がその記法に交差したときだけ記法文字を開示するものです。
ADR 0003は、文書モデルを持つ構造化エディタへの移行を「任意のAsciiDocソースを無損失で
往復させる保証を作りにくい」として不採用にしており、この判断は変えません。CodeMirror 6の
装飾(Decoration)レイヤは、文字列を書き換えずに表示だけを変えられるため、この体験を
既存の編集基盤の上で実現できます。

装飾には「原文のどこにどの記法があるか」という情報が必要です。ADR 0003はAsciiDocの解析を
サーバー側のAdocWeaveへ一本化しており、ブラウザー側に簡易の解析を持ち込むと、装飾と
実際の描画・診断が食い違います。

== 決定

編集画面の装飾は、AdocWeaveの解析結果から導いた *span注釈* だけを根拠にします。span注釈とは、
記法の種類(強調、見出し、数式など)と、その記法が原文で占めるUTF-8バイトオフセットの範囲、
記法文字を除いた本文部分の範囲、カーソルが離れているときに折り畳める記法文字の範囲を
列挙したものです。

span注釈は既存のプレビューAPI(``POST /api/v3/notes/preview``)の応答へ``spans``として追加し、
検証・診断・HTML生成と同じ1回の解析から導きます。専用のendpointは作らず、二重解析を
避けます。ブラウザー側はAsciiDocを解析しません。

編集中の追従は次の規律で行います。

* 装飾はspan注釈と選択範囲から導く。本文が変わったら、既存の装飾を編集の変換
  (CodeMirrorの``RangeSet.map``)で追従させ、次に届いた解析結果で置き換える。
* span注釈は、解析した本文と編集欄の本文が完全に一致する場合だけ採用する
  (診断表示と同じ規律)。
* IME変換中はプレビュー取得を開始しないという既存の動作を保ち、変換中に装飾の
  更新を開始しない。
* 装飾は無効化でき、無効時は素の原文を表示する。装飾の有無は保存される内容へ影響しない。

== 代替案

[cols="1,1",options="header",]
|===
|選択肢
|評価
|ブラウザー側の簡易解析(CodeMirrorの構文拡張や独自の正規表現)
|入力へ即時に追従できるものの、AdocWeaveの解析と食い違う装飾が生じる。ADR 0003が
公式AsciiDoc構文拡張を採用しなかった理由と同じであり不採用
|AdocWeaveをWebAssemblyへ変換しブラウザー内で同期解析する
|装飾は打鍵ごとに即時になるが、AdocWeave側にwasm境界とCIの恒久的な保守が必要になり、
サーバーの固定revisionと配布物の食い違いを防ぐ検査、Content Security Policyへの
``wasm-unsafe-eval``追加というセキュリティ境界の変更も伴う。体験の検証前に払う対価では
ないため今回は見送り
|プレビューAPIの応答へspan注釈を追加する(採用)
|新規に入力した記法の装飾はデバウンスと往復の分(体感で1秒未満)遅れるが、装飾済みの
文書は編集へ即時追従する。診断が同じ経路・同じ遅延で受け入れられている実績があり、
解析の単一実装と既存のセキュリティ境界を保てる
|===

== 結果

AdocWeaveは固定中のrevisionで必要な意味モデル(``Analysis::document()``と
``semantic::walk``、各ノードの範囲情報)を公開しており、AdocWeave側の変更なしで
span注釈を導けます。応答へ``spans``が加わるためプレビュー応答の契約は変わりますが、
受理するAsciiDocの範囲は変わらないため``AUTHORING_PROFILE_VERSION``は据え置きます。

記録時点では、日本語の地の文で制約付き引用符(``*太字*``)がCJK文字の隣接で認識されない
制限がありました。この制限はKeishiS/adocweave#576で解消し、AdocWeave 0.41.0の取り込みから
制約付き記法もそのまま装飾されます。

== 再検討条件

* AdocWeaveがspan注釈に相当する公開APIの形を変えた場合
