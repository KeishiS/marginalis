= リリース手順

[#top]
この文書は、Marginalisをリリースする手順を定めます。版ごとの変更内容、互換性への影響、
移行手順は https://github.com/KeishiS/marginalis/releases[GitHub Releases]のRelease Notesを
正本とし、リポジトリ内には蓄積しません。受入の確認項目は xref:acceptance.adoc#top[受入基準]を
参照してください。

[arabic]
. Cargo workspaceの版を上げ、``cargo make verify``の成功を確認して版上げのPull Requestを
作成します。版とNix packageの整合は``verify``内の``release-metadata``が検査します。
. 外部のGit依存が意図した公開版を指していることを確認します。``cargo make shared-authorization-server``が、
共有Authorization Serverの2 crateについて、版が同じであること、同じリポジトリの40桁の完全SHAから取得して
いること、``Cargo.lock``の取得元が宣言と一致すること、``flake.nix``に取得ハッシュがあることを検査します。
指しているSHAが上流の公開済みタグに対応することの確認は
xref:mcp-authorization-server-maintenance.adoc#top[MCP Authorization Serverの保守]のタグ解決手順に
従います。上流の未公開コミットや、タグが付いていないコミットを指したまま公開しません。
. xref:acceptance.adoc#top[受入基準]の人手受入を実施し、実施日、結果、失敗または未実施の項目が
ある場合の判断をリリース用Pull Requestへ記載します。
. 必須チェックの成功を確認し、 xref:development.adoc#top[GitHubを使う開発手順]のマージ方式で
Pull Requestを``main``へマージします。
. ``main``の先端で``release-gate``ワークフローを手動実行します。``release_tag``には作成予定の
タグを入力し、検証の成功を確認します。
. 検証した``main``の先端へリリースタグを作成してプッシュし、タグのプッシュで再実行される
``release-gate``も成功することを確認します。
. タグに対するGitHub Releaseを下書きとして作成し、Release Notesへ変更内容、互換性への影響、
必要な場合はデータの移行手順を記載します。公開した版の機械可読な契約を取得できるように、
対象タグに記録された``docs/openapi.json``と``docs/mcp-tools.json``を同名のassetとして下書きへ
添付します。作業treeのファイルは使わないため、タグの検証後に``main``が進んでも公開内容は変わりません。
``--verify-tag``で既存タグだけを受け入れ、タグ名の入力誤りによる新しいタグの作成を防ぎます。
+
[source,sh]
----
release_tag=v<MAJOR>.<MINOR>.<PATCH>
release_assets=$(mktemp -d)
trap 'rm -rf "$release_assets"' EXIT
git show "$release_tag:docs/openapi.json" >"$release_assets/openapi.json"
git show "$release_tag:docs/mcp-tools.json" >"$release_assets/mcp-tools.json"
gh release create "$release_tag" --verify-tag --draft \
  "$release_assets/openapi.json" "$release_assets/mcp-tools.json" \
  --title "$release_tag" --notes-file <Release Notesのファイル>
----
. 下書きの``isDraft``が``true``であり、``assets``に``openapi.json``と``mcp-tools.json``だけが
それぞれ一つずつ含まれることを確認します。不足や重複がある場合は公開せず、下書きを修正します。
+
[source,sh]
----
test "$(gh release view "$release_tag" --json isDraft,assets \
  --jq '(.isDraft == true) and (([.assets[].name] | sort) == ["mcp-tools.json", "openapi.json"])')" = true
----
. Release Notesとassetの確認後に、下書きを公開します。
+
[source,sh]
----
gh release edit "$release_tag" --draft=false
----

パッチ版は予定へ固定せず、各通常版の公開後に、互換性を変えない不具合や移行手順の修正が必要に
なった場合だけ公開します。リリースを中止する場合は、タグとGitHub Releaseを作成せず、必要な修正を
通常のPull Requestとして続けます。過去の版の変更内容と移行手順はGitHub Releasesを、v0.36.0以前の記録は各タグ上の
``CHANGELOG.adoc``と``docs/acceptance-results/``を参照してください。

日次バックアップ、30世代の保持、四半期の復元確認については
xref:../user-guide/nixos.adoc#top[NixOSでの運用]を参照してください。
